# Portfolio Web App Walkthrough

Use this script for a short reviewer walkthrough after the database migration and authentic content are complete.

## Public site

1. Open `https://agegnehuy.com` on desktop and mobile.
2. Introduce the hero positioning statement and use the Work, Services, Process, About, Insights, FAQ, and Contact navigation links.
3. Filter the project index by category and open one complete case study directly by URL. Show its context, role, dates, challenge, approach, outcome, technology, credits, live/source links, and screenshot gallery.
4. Open a service detail page and its contact action.
5. Search and filter Insights, then open a full article.
6. Expand FAQ items with the keyboard.
7. Submit a contact message and testimonial. Show real success and error feedback.
8. Open Privacy, Terms, and an invalid URL to demonstrate the 404 page.

## Admin site

1. Sign in using reviewer credentials shared privately.
2. Show the overview counts.
3. Create or edit a project, complete its case-study fields, preview it, and publish it.
4. Create or edit a service and article and toggle publication status.
5. Review a testimonial and approve it only after confirming publication permission.
6. Edit the About content and confirm the public page updates.
7. Sign out and confirm protected routes redirect to login.

## Final checks

- Repeat the direct case-study URL in a private browser window.
- Confirm the contact email arrives at `agegnehuyelib01@gmail.com`.
- Do not show credentials, private submissions, or environment values in the recording.
